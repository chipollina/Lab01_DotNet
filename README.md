Ответы на вопросы:
1. Console.Write() отличается от Console.WriteLine() тем, что Console.WriteLine() выводит текст с переходом на новую строку, а Console.Write() без.
2. Если попытаться присвоить переменной типа int значение 3.14, то произойдет ошибка так как это значение не является целым числом, для такого типа чисел нужно использовать double. 
3.  10 / 3 в C# даёт 3, а не 3.333 потому что оба числа являются целыми, для того чтобы получить дробный результат нужно преобразовать к типу double.
4. Var - компилятор который сам определяет тип переменной по значению. В отличии от Python в C# тип переменной определяется всего один раз и в дальнейшем его нельзя поменять.
